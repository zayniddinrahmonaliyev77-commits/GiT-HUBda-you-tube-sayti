## 📖 Loyiha haqida

Bu loyiha — YouTube veb-saytining interfeysini **faqat HTML5 va CSS3** yordamida qayta yaratish orqali, real dunyodagi murakkab UI tuzilmalarini tushunish va sinash maqsadida qilingan amaliy ish.

JavaScript ishlatilmagan — barcha joylashuv, dizayn va video kartochkalar **sof CSS (Flexbox/Grid)** asosida qurilgan.

## ✨ Xususiyatlari

- 🧭 YouTube uslubidagi **navigatsiya paneli** (Bosh sahifa, Shorts, Obunalar)
- 📂 Yon menyu — **Tarix**, **Yoqqanlar** bo'limlari
- 🏷️ Kategoriya filtrlari — Barchasi, Dasturlash, Musiqa, O'yinlar, Yangiliklar
- 🎬 Video kartochkalar tuzilmasi — sarlavha, kanal nomi, ko'rishlar soni va yuklangan vaqti
- 📱 Video oynalar **YouTube embed** orqali ulangan

## 🛠️ Texnologiyalar

| Texnologiya | Vazifasi |
|---|---|
| **HTML5** | Sahifa tuzilmasi va semantikasi |
| **CSS3** | Dizayn, joylashuv (layout) va uslublar |

## 📂 Sahifa tuzilmasi

```
├── index.html      # Asosiy sahifa
├── style.css        # Barcha uslublar
└── assets/          # Rasm va ikonalar
```

## 🚀 Loyihani ishga tushirish

```bash
# Repozitoriyani klonlash
git clone <repo-havolasi>

# Loyiha papkasiga kirish
cd youtube-kloni

# index.html faylini brauzerda oching
```

Yoki oddiygina `index.html` faylini brauzerda ochish kifoya — hech qanday qo'shimcha o'rnatish (npm, build) talab qilinmaydi.

## 🎯 Nimalarni o'rgandim

- CSS Grid va Flexbox yordamida murakkab, ko'p ustunli layout qurish
- Real dunyo interfeyslarini (YouTube) piksel darajasida qayta yaratish
- Responsive va tartibli kod yozish
